# Объяснение Network запросов в Next.js

## 🔍 Что вы видите в DevTools Network

### ✅ Нормальные запросы (не ошибки):

#### 1. **Webpack Hot Update** (`*.webpack.hot-update.json`)
- **Что это:** Файлы для Hot Module Replacement (HMR)
- **Зачем:** Автоматическое обновление страницы при изменении кода
- **Когда:** При сохранении файлов во время разработки
- **Статус:** ✅ Нормально, только в dev режиме

#### 2. **React Server Components** (`menu?_rsc=...`)
- **Что это:** Запросы серверных компонентов Next.js
- **Зачем:** Загрузка данных с сервера для страниц
- **Параметр `_rsc`:** Идентификатор для RSC протокола
- **Статус:** ✅ Нормально, стандартный механизм Next.js

#### 3. **WebSocket** (`webpack-hmr`)
- **Что это:** WebSocket соединение для HMR
- **Зачем:** Двусторонняя связь между браузером и сервером
- **Статус:** ✅ Нормально, только в dev режиме

## 📊 Типы запросов в вашем проекте

### API запросы (ваши):
- `GET /api/menu` - получение меню
- `POST /api/orders` - создание заказа
- `POST /api/reservations` - бронирование
- `GET /api/reviews` - отзывы
- `POST /api/payments` - платежи

### Next.js системные (автоматические):
- `*?_rsc=*` - React Server Components
- `*.webpack.hot-update.json` - Hot Module Replacement
- `webpack-hmr` - WebSocket для HMR
- `/_next/static/*` - статические файлы
- `/_next/webpack-hmr` - WebSocket соединение

---

## 🎯 Как отличить ваши API от системных

### Ваши API запросы:
- Начинаются с `/api/`
- Имеют понятные названия: `menu`, `orders`, `reservations`
- Возвращают JSON данные
- Вызываются из вашего кода

### Системные запросы Next.js:
- Содержат `_rsc`, `webpack`, `_next`
- Автоматические, не требуют вашего кода
- Нужны для работы Next.js
