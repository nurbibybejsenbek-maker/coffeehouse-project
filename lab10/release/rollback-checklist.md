# Кері қайтару чек-парағы

Сағат инцидент анықталған минуттан басталады. Мақсат — 30 минут, Elite шегі — 1 сағаттан аз. Осы ұзақтық келесі DORA есебіндегі қалпына келтіру уақытының үлгісі болады. Оны қысқарту үшін журналды ерте жаппаңыз.

Алдыңғы жасыл SHA: `________________`  
Бұзылған SHA: `________________`  
Анықталды: `____:____`  
Қалпына келді: `____:____`  
Айырма: `____` минут

## 0–5 минут — жариялау (Назгүл)

- [ ] Инцидент жарияланды: не сынды, кім зардап шегеді (қызметкер / барлық қонақ).
- [ ] Элеонора мен Нұрбиби шақырылды.
- [ ] Қонаққа бір сөйлем: «Тапсырыс пен брондау уақытша тоқтады, жаңартып жатырмыз.»
- [ ] Feature flag болса, оны өшіру жеткілікті ме — иә / жоқ.

## 5–15 минут — оралу (Нұрбиби)

Flag жеткілікті болса:

- [ ] Flag өшірілді. Жаңа құрастыру күтілмейді.
- [ ] Қонақ ескі мінезді көреді.

Flag жоқ болса, алдыңғы артефакт:

- [ ] Репозиторий түбінде:

```bash
git fetch origin
git checkout <previous-green-sha>
docker compose build app
docker compose up -d --no-deps app
```

- [ ] `prisma db push` іске қосылмады.
- [ ] Сұлба осы релизде өзгермеген. SQLite файлы орнында қалды.
- [ ] Сұлба өзгерген болса ғана, терезе алдындағы көшірме қайта қойылады:

```bash
cp prisma/backups/dev.db.YYYYMMDDHHMM prisma/dev.db
```

Көшірме жоқ болса, дерек файлын қолмен өңдемеңіз. Сайтты ескі кодпен көтеріп, Назгүлге «дерек тәуекелі» деп жазыңыз.

## 15–25 минут — smoke (Элеонора және Нұрбиби)

- [ ] Басты бет ашылады.
- [ ] Мәзір тізімі жүктеледі.
- [ ] Тапсырыс формасы sandbox-та жіберіледі.
- [ ] Брондау сақталады.
- [ ] Админ кіру және асүй тізімі ашылады.

Кез келген тармақ қызыл болса, келесі ескі SHA-ға түсіңіз. Жаңа түзетуді осы сағатта жазбаңыз.

## 25–30 минут — жабу (Назгүл)

- [ ] Қонаққа: «Қайта істейді. Жіберілмеген тапсырысты қайталаңыз.»
- [ ] Тапсырыс берушіге: не сынды, қай SHA-ға оралдық, қанша минут кетті, дерек жоғалды ма (жоқ / иә).
- [ ] Журнал толды. Бұл бір сәтсіз өзгеріс. Оны келесі есептен алып тастамаңыз: сәтсіздік үлесі осыдан шығады.
- [ ] Келесі жұмыс күні ретро: неге smoke жіберіп алды, қандай тест құбыржолға қосылады. Жаза жоқ, өзгеріс бар.
