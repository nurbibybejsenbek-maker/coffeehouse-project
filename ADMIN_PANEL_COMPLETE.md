## 📝 Примечания

1. **Локализация**: Полная локализация на казахском языке. Русский и английский можно расширить по аналогии.

2. **Статусы заказов**: Обновлены на NEW, PAID, COOKING, READY, COMPLETED, CANCELED

3. **База данных**: Обновлена схема Prisma, добавлено поле `isPublished` для Review

4. **Графики**: Используется библиотека recharts для отображения графиков продаж

5. **Безопасность**: Все админ-маршруты защищены через middleware и layout проверки
