# Құн есебі. Пікірді белгілеу

Есеп күні: 20 қараша 2026. Барлық тариф сол күні оқылған ресми беттен. Токен шикі болжам емес: v2 сұранысының әрқайсысы `tiktoken` арқылы, `gpt-4.1-mini` кодтауымен саналды. Кодтау табылмаса, есеп `o200k_base` кодтауына түседі. Чат үстемесі қосылған: әр хабарламаға 3 токен, жауапты бастауға 3 токен.

Шығыс токені жергілікті модельдің JSON жауабынан саналды. Ақылы API шақырылмады. Ұзындық сол жауаптың ұзындығы, gpt-4.1-mini дәл сондай мәтін шығарады деген сөз емес. Қысқа JSON үшін айырма кіші, бірақ бұл шектеу жасырылмайды.

## Көлем

8-апта, 12-ай: 6 480 тапсырыс. Пікір қалдыру үлесі жоспарлық 8%. Бұл өлшенген конверсия емес.

```
база   = 6 480 × 0,08        = 518,4 пікір / ай
×10    = 518,4 × 10          = 5 184 пікір / ай
```

Он еселік сценарий тапсырыс он есе өссе немесе әр тапсырыс пікірге жақындаса деген жүктеме. Екеуі бір формула.

## Коммерциялық API

Таңдалған модель: OpenAI `gpt-4.1-mini`, standard тариф.

| | 1 млн токен, USD |
|---|---|
| Кіріс | 0,40 |
| Шығыс | 1,60 |
| Кэштелген кіріс | 0,10 |

Дереккөз: [OpenAI API pricing](https://developers.openai.com/api/docs/pricing), 20 қараша 2026.

Кэштелген бағаны негізгі есепке кіргізбейміз. Промпт қысқа, кэш шегіне жетпеуі мүмкін, ал промпт нұсқасы ауысса кэш жоғалады. Негізгі есеп әр токенді толық кіріс бағасымен алады. Бұл жоғарғы жақ.

Сезімталдық: сол беттегі `gpt-4o-mini`, кіріс 0,15, шығыс 0,60. Ол арзан, бірақ модель беті оны ескірген деп белгілейді. Шартты соған байламаймыз.

Бір сұраныс:

```
c = (кіріс_токен / 1_000_000) × 0,40 + (шығыс_токен / 1_000_000) × 1,60
ай = сұраныс_саны × c
```

Теңге: 8-аптаның жоспарлық бағамы, 1 USD = 520 KZT. Бұл Ұлттық банктің сол күнгі бағамы емес.

## Өз серверіміз

Ашық модель: Qwen2.5, өлшем 7B деңгейінде Q4. Ол 24 GB бейнежадқа сыяды. Салыстыру үшін RunPod RTX 3090.

| Орта | USD / сағат |
|---|---|
| Secure Cloud | 0,50 |
| Community Cloud | 0,22 |

Дереккөз: [RunPod pricing](https://www.runpod.io/pricing), 20 қараша 2026. RunPod айлық баға жарияламайды. Ай = сағат × 730, мұнда 730 = 365 / 12 × 24.

```
Secure    = 0,50 × 730 = 365,00 USD / ай
Community = 0,22 × 730 = 160,60 USD / ай
```

Өндірістік салыстыру Secure. Пікірде телефон кездеседі, Community бөгде машина. Community бағасы «арзан болар еді» деген жол, таңдау емес.

Жергілікті өлшемдегі 3B модель бағаны өзгертпейді: GPU бәрібір ай бойы қосулы тұрады. 3B-ны кішірек GPU-да ұстауға болады, бірақ ресми беттегі ең жақын әрқашан қосулы нұсқа ретінде 3090 алынды.

## Қай жерде GPU арзан

```
N* = GPU_ай / c
```

N* сұраныстан асқанда ғана әрқашан қосулы Secure GPU API-ден арзан. Осы көлемде, он еселісте де, API арзан. GPU-ны ақша үшін емес, дерек машинадан шықпасын деген себеппен ғана ұстауға болады. Пилотта ол да керек емес: Ollama модератор машинасында, айлық GPU шоты жоқ.

Өлшенген орташа токен, айлық сома және N* төменде. Қайта шығару: `python scripts/cost_report.py`.
