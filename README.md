# # CoffeeHouse — кофехана веб-сайты

## Жоба туралы

CoffeeHouse — жергілікті кофеханаға арналған веб-сайт. Жобаның мақсаты — кофехана туралы ақпаратты ыңғайлы ұсыну және клиенттерге мәзірді қарау, онлайн-тапсырыс беру, үстел брондау мүмкіндігін жасау.

## Жобаның мақсаты

* Кофехана мәзірін онлайн көрсету;
* Клиенттерге өзімен алып кетуге тапсырыс беру мүмкіндігін ұсыну;
* Үстел брондау процесін жеңілдету;
* Кофехана туралы байланыс және орналасу ақпаратын ұсыну;
* Клиенттердің қайталама тапсырыстарын қолдауға арналған адалдық бағдарламасын қарастыру.

## Негізгі функционалдар

* Мәзірді қарау;
* Өнімдер туралы ақпарат;
* Онлайн-тапсырыс беру;
* Үстел брондау;
* Адалдық бағдарламасы;
* Байланыс ақпараты;
* Карта және орналасу орны.

## Жеткізу моделі

Жоба үшін **Adaptive (Agile/Scrum)** моделі таңдалды.

Бұл модель талаптарды жоба барысында нақтылауға, пайдаланушы кері байланысын ескеруге және функционалдарды қысқа спринттер арқылы әзірлеуге мүмкіндік береді.

Толық шешім: `docs/adr/ADR-001-delivery-model.md`

## Жоба құралдары

* GitHub — кодты және құжаттарды сақтау;
* GitHub Projects — тапсырмаларды басқару;
* Git — нұсқаларды басқару;
* HTML / CSS / JavaScript — веб-әзірлеу.

## Жұмыс ережелері

* Әр тапсырма GitHub Issue ретінде тіркеледі.
* Әр функционал жеке branch-та әзірленеді.
* Commit атаулары бекітілген келісімге сәйкес жазылады.
* Pull Request арқылы өзгерістер тексеріледі.
* Аяқталған тапсырмалар Projects тақтасында Done статусына ауыстырылады.
