# CoffeeHouse — Жоба жарғысы

## 1. Жоба атауы

CoffeeHouse — кофеханаға арналған веб-сайт.

## 2. Жоба мақсаты

Кофехана клиенттеріне мәзірді онлайн қарауға, өзімен алып кетуге тапсырыс беруге және үстел брондауға мүмкіндік беретін ыңғайлы веб-сайт әзірлеу.

## 3. Тапсырыс беруші

Жергілікті шағын кофехана.

## 4. Мүдделі тараптар

* Кофехана иесі;
* Кофехана қызметкерлері;
* Сайт пайдаланушылары;
* Жоба командасы.

## 5. Негізгі нәтижелер

* Жұмыс істейтін веб-сайт прототипі;
* Мәзір беті;
* Онлайн-тапсырыс формасы;
* Үстел брондау формасы;
* Байланыс және карта бөлімі;
* Жоба құжаттамасы;
* GitHub Projects жұмыс тақтасы.

## 6. Команда

* Жаукарбекова Элеонора — BA / Frontend;
* Естемес Назгүл — PM / QA;
* Бейсенбек Нұрбиби — SA / Backend.

## 7. Шектеулер

* Үш адамнан тұратын команда;
* Семестрлік мерзім — 15 апта;
* Ашық және тегін технологиялық стек;
* Шектеулі уақыт пен ресурстар.

## 8. Жеткізу моделі

Adaptive (Agile/Scrum).

## 9. Жұмыс тәсілі

Жоба қысқа спринттер арқылы орындалады. Әр спринт соңында жұмыс нәтижесі тексеріліп, келесі міндеттер нақтыланады.

## 10. Жетістік критерийлері

* Негізгі веб-беттердің жұмыс істеуі;
* Онлайн-тапсырыс және брондау формаларының болуы;
* Интерфейстің қолдануға ыңғайлылығы;
* Құжаттаманың толықтығы;
* GitHub Projects тақтасының жүргізілуі.
