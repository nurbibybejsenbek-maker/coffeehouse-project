# Админ-панель - Архитектура

## 📍 Расположение

Админ-панель полностью интегрирована в основное приложение и работает на **одном сервере** с публичным сайтом.

## 🏗️ Структура

```
coffeehouse.kz/                    # Один домен, один сервер
├── /kk/                           # Публичный сайт (казахский)
├── /ru/                           # Публичный сайт (русский)
├── /en/                           # Публичный сайт (английский)
├── /admin/                        # Админ-панель (защищена)
│   ├── /admin/login              # Страница входа
│   ├── /admin                    # Dashboard
│   ├── /admin/orders             # Управление заказами
│   ├── /admin/reservations       # Управление бронированиями
│   ├── /admin/menu               # Управление меню
│   ├── /admin/customers          # Управление клиентами
│   ├── /admin/reviews            # Управление отзывами
│   └── /admin/api                # API документация
└── /api/                          # Общие API endpoints
```

## 🔒 Безопасность

### Защита маршрутов

1. **Middleware** (`middleware.ts`):
   - Проверяет авторизацию для всех `/admin/*` маршрутов
   - Требует роль `ADMIN` или `STAFF`
   - Исключает `/admin/login` из проверки

2. **Layout защита** (`app/admin/layout.tsx`):
   - Server-side проверка сессии
   - Редирект на `/admin/login` если не авторизован
   - Проверка роли пользователя

3. **API защита** (`lib/api-auth.ts`):
   - Проверка NextAuth токена для админ-операций
   - Разделение прав доступа для админов и клиентов

- **ADMIN**: Полный доступ ко всем функциям
- **STAFF**: Доступ к управлению заказами и бронированиями

## 🚀 Запуск

Админ-панель доступна по адресу:
- **Локально**: `http://localhost:3000/admin/login`
- **Продакшн**: `https://coffeehouse.kz/admin/login`

## 📦 Компоненты

### Основные файлы

- `app/admin/layout.tsx` - Layout с проверкой авторизации
- `app/admin/login/page.tsx` - Страница входа
- `app/admin/page.tsx` - Dashboard
- `components/admin-navbar.tsx` - Навигация админ-панели
- `components/session-provider.tsx` - Провайдер сессии NextAuth

### API Endpoints

Все админ-операции используют общие API endpoints в `/app/api/`:
- `/api/orders` - Управление заказами
- `/api/reservations` - Управление бронированиями
- `/api/menu` - Управление меню
- `/api/admin/customers` - Управление клиентами
- `/api/reviews` - Управление отзывами

## 🔄 Интеграция

Админ-панель использует:
- ✅ Тот же Next.js сервер
- ✅ Тот же Prisma клиент и базу данных
- ✅ Те же API endpoints
- ✅ Тот же NextAuth для аутентификации
- ✅ Те же UI компоненты (shadcn/ui)

## 📝 Особенности

1. **Без интернационализации**: Админ-панель не использует префиксы локалей (`/kk/admin`), работает напрямую через `/admin`
2. **Отдельный layout**: Админ-панель имеет свой layout без Navbar/Footer публичного сайта
3. **SessionProvider**: Использует NextAuth SessionProvider для клиентских компонентов

## 🛠️ Разработка

### Добавление новой страницы админ-панели

1. Создайте файл в `app/admin/your-page/page.tsx`
2. Страница автоматически будет защищена через `app/admin/layout.tsx`
3. Добавьте ссылку в `components/admin-navbar.tsx`

### Добавление нового API endpoint

1. Создайте файл в `app/api/your-endpoint/route.ts`
2. Используйте `requireAuth(request, true)` для защиты админ-операций
3. Проверьте роль через `auth.isAdmin`
