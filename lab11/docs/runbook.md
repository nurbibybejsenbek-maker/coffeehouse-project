| | |
|---|---|
| Қолданылады | Демо, http://127.0.0.1:3000 . Uptime Kuma http://127.0.0.1:3001 |
| Уақыт | Asia/Almaty. Жұмыс күнгі кезек 10:00–18:00 |
| Байланыс | Кезекші чаты. Тапсырыс берушіге жазбаша хабар, 15 минут ішінде, егер SEV-1 немесе SEV-2 10 минуттан ұзақ болса |

## Қашан ашылады

- Uptime Kuma екі рет қатарынан қызыл: `/kk` немесе `GET /api/menu`.
- `POST /api/orders` 5xx, не қонақ растау бетін көрмейді.
- Журналда `database is locked`.

Бір реттік 400 (бос форма) инцидент емес.

## Деңгей

| Деңгей | Шарт | Кім оятады |
|---|---|---|
| SEV-1 | Тапсырыс жолы 15 минуттан ұзақ жабық, не дерек файлы бүлінген | Кезекші бәрін шақырады |
| SEV-2 | Мәзір тірі, тапсырыс 5xx немесе үзік-үзік | Кезекші және стенд адамы |
| SEV-3 | Тек әкімші беті | Келесі жұмыс сағаты |
| SEV-4 | Көшірме, бір тілдегі сирек жазу | Триаж |

Осы демо үшін инцидент командирі — сол сәттегі кезекші. Командир түзетуді өзі жазбайды. Ол деңгейді атайды, уақытты жазады, біреуге стендті, біреуге хабарламаны береді. 10–18 сағатта шешімді Естемес Назгүл, стендті Бейсенбек Нұрбиби, қонақ мәтінін Жаукарбекова Элеонора жүргізеді. Біреуі жоқ болса, қалған екеуі рөлді бөліседі, командир біреу ғана.

## Алғашқы 15 минут

1. Белгіні қабылдау. Уақытты жазу.
2. Деңгейді айту. SEV-2 болса, жаңа релиз тоқтатылады.
3. Екі тексеру, біріншісі оқу, екіншісі жазу емес:

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:3000/kk
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:3000/api/menu
```

4. Контейнерлер:

```bash
docker ps --format '{{.Names}} {{.Status}}'
docker logs --tail 80 coffeehouse-app
```

5. Тапсырыс берушіге қысқа хабар, егер 10 минуттан асса. Үлгі төменде.

`POST /api/orders` бұл қадамда жіберілмейді. Ол артық тапсырыс ашады.

## Не іздейміз

**Файл құлпы.** Журналда `database is locked`. Себебі app `file:./prisma/dev.db` жазады, ал екінші процесс (seed, Prisma Studio) сол файлды ашқан. PostgreSQL контейнері жасыл болуы мүмкін және бұл ештеңені дәлелдемейді: қолданба оны қолданбайды.

**Релизден кейінгі регрессия.** Соңғы 30 минутта контейнер қайта жиналса және қате сол минуттан басталса, 10-апта кері қайтару чек-парағы ашылады. `prisma db push` бұл жерде іске қосылмайды.

**Тек әкімші.** Мәзір 200, қонақ тапсырысы 201, әкімші ғана құласа, бұл SEV-3. Тапсырыс жолын қайта көтермейміз.

## Түзету

Құлпы болса:

1. Екінші жазушыны тоқтату. Seed және Prisma Studio жабылады.
2. App қайта көтеріледі:

```bash
docker compose restart app
```

3. Дерек файлын өшірмеу. Көшірме релиз чек-парағында алынған болса, соған қол тигізбеу.
4. Төмендегі тексеруден өткен соң ғана қонаққа «қайта көріңіз» деу.

Қайта көтеру көмектеспесе және қате соңғы шығарудан басталса, алдыңғы жасыл SHA-ға кері қайтару. Команда 10-апта `rollback-checklist.md` ішінде. Командир кері қайтаруды ашады, стенд адамы орындайды.
